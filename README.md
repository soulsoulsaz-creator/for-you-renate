# A Podcast About Us

A zero-cost, mobile-first static website designed for GitHub Pages.

## Put your real content in
- `assets/audio/episode-01.mp3` through `episode-08.mp3`
- `assets/images/` for photos you decide to add
- `script.js` for episode titles/descriptions and letters
- `index.html` for your story/timeline text

## GitHub Pages
Create a repository, upload these files to the repository root, then enable GitHub Pages from **Settings → Pages** and publish from the `main` branch/root.

Important: GitHub Pages sites are publicly reachable by default. Do not upload private passwords, private keys, or anything you would not want exposed on the internet.
